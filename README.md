## 🚀 Architectural & Engineering Highlights

- **Spatial Three.js / R3F Canvas**: Continuous camera choreographies with GSAP lerps and custom GLSL paint-brush shaders.
- **Asynchronous Shader Compilation**: Enforces `gl.compileAsync` during the preloading phase to eliminate main-thread frame drops.
- **Adaptive Station Portal Guards**: Dynamic unmounting of Drei `<Html>` overlays across 3D station view angles to guarantee zero card collisions or clipping.
- **Unified Global Audio Engine**: Centralized SFX and BGM state machine with hotkey muting (<kbd>M</kbd>) and zero memory leaks.
- **SEO & Accessibility**: Invisible semantic indexing trees rendered for search engines and screen readers alongside the WebGL canvas.

## 🛠️ Local Development Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/GodSpeedn/wispr-flow-portfolio.git
   cd wispr-flow-portfolio
   ```

2. **Install dependencies:**
   *(Requires Node.js v20+)*
   ```bash
   npm install
   ```

3. **Start local dev server:**
   ```bash
   npm run dev
   ```

4. **Production Build:**
   ```bash
   npm run build
   npm run preview
   ```
